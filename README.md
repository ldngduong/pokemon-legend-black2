## Hướng Dẫn Cập Nhật & Cài Đặt

1. **Người dùng mới:**
   - Tải tệp ROM .nds bản mới nhất từ mục [Releases](https://github.com/ldngduong/pokemon-legend-black2/releases).
   - Chạy trên giả lập khuyên dùng: **melonDS 1.0/1.1** hoặc **DeSmuME 0.9.13** trên PC; **melonDS** hoặc **Delta** trên Android / iOS.

2. **Người dùng đã có bản Beta 1.0.5:**
   - Mở ứng dụng Launcher Windows và bấm nút **UPDATE** để tự động cập nhật delta patch (chỉ 609 KB).
   - Hoặc tải tệp vá Pokemon_Legend_Black_2_1.0.5_to_1.0.6.bps đính kèm trong Release và áp dụng vào ROM cũ qua công cụ BPS patcher (FLIPS, UniPatcher...).
